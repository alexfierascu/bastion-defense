# AI Rules

Status: Approved

---

# Documentation First

Never write code before reading the documentation.

---

# Never Guess

If documentation is missing:

STOP.

Do not invent.

Request documentation.

---

# Visual Style

Never introduce:

Glassmorphism

Generic fantasy

Neon colors

Rounded mobile UI

Random gradients

Anime aesthetics

Sci-fi assets

---

# Architecture

Prefer reusable systems.

Never duplicate code.

Never duplicate components.

Never duplicate game logic.

---

# Animation

Everything should feel alive.

Nothing should attract unnecessary attention.

Movement should be subtle.

---

# Performance

60 FPS minimum target.

Use GPU accelerated transforms.

Avoid layout thrashing.

Avoid unnecessary rerenders.

---

# If Unsure

Choose the simpler architecture.

Never over-engineer.

Never optimize prematurely.

Always leave room for future expansion.
