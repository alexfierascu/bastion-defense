# Quality Checklist

Status: Approved

Version: 1.0

Owner: Creative Direction

---

# Purpose

This document defines the minimum quality requirements for every asset, feature, screen, animation and environment before it can be considered complete.

Nothing enters the game without passing this checklist.

---

# Philosophy

Players do not experience individual assets.

Players experience the entire game.

One weak asset lowers the quality of everything around it.

Quality is the minimum standard.

Not the goal.

---

# Universal Rule

Every asset must satisfy four questions.

1. Is it believable?

2. Is it readable?

3. Does it support gameplay?

4. Does it belong to Bastion Defense?

If any answer is "No",

the asset is rejected.
