# Visual Language

Status: Approved

Version: 1.0

Owner: Art Direction

---

# Purpose

This document defines the visual language used throughout Bastion Defense.

Visual language is the collection of rules that allows players to recognize the game's identity instantly, regardless of what they are looking at.

If a screenshot loses its identity when the logo is removed, the visual language has failed.

---

# Core Identity

Bastion Defense is built around one central idea:

> Civilization survives because it learned to build with nature instead of conquering it.

Every asset must reinforce this idea.

---

# Visual Formula

Every scene should contain the following relationship:

Human Engineering

+

Living Nature

+

Visible History

+

Purposeful Lighting

=

Bastion Defense

Removing any one of these pillars weakens the identity.

---

# Civilization

Civilized structures are:

Engineered.

Practical.

Heavy.

Stable.

Repairable.

Permanent.

They are never elegant for the sake of elegance.

Beauty comes from craftsmanship.

---

# Nature

Nature is an ally.

It softens.

Protects.

Supports.

Frames.

Connects.

Nature never overwhelms civilization.

It coexists.

---

# History

Every environment should feel inherited.

The player should never feel like the first person to visit a place.

Examples

Repaired walls.

Worn stairs.

Wheel marks.

Old banners.

Weathered stone.

Ancient trees.

Visible maintenance.

History should always be visible.

---

# Shape Language

Civilized

Squares.

Rectangles.

Verticality.

Symmetry.

Strong silhouettes.

Nature

Curves.

Roots.

Branches.

Irregular growth.

Enemies

Sharp angles.

Broken silhouettes.

Asymmetry.

Aggressive forms.

---

# Material Language

Stone

Strength.

Oak

Warmth.

Bronze

Prestige.

Iron

Function.

Leather

Craftsmanship.

Canvas

Military.

Roots

Life.

Moss

Time.

Every material communicates something.

---

# Scale Language

Large structures communicate safety.

Large trees communicate age.

Wide bridges communicate logistics.

Tall towers communicate vigilance.

Small details reward observation.

Scale always supports gameplay.

---

# Contrast Language

Warm

Safety.

Cold

Unknown.

Bright

Importance.

Dark

Supporting information.

High contrast

Interaction.

Low contrast

Atmosphere.

---

# Landmark Language

Every map must contain landmarks.

Examples

The Great Tree.

Main Gate.

Bell Tower.

North Watch.

Bridge.

Courtyard.

Landmarks should be recognizable from multiple camera positions.

---

# Movement Language

Nothing remains perfectly still.

Trees sway.

Grass moves.

Smoke rises.

Fog drifts.

Water flows.

Torch flames flicker.

Movement should remain subtle.

---

# Weather Language

Weather changes atmosphere.

Never identity.

A rainy Bastion should still immediately look like the Bastion.

Snow should enhance composition.

Fog should enhance depth.

Storms should enhance tension.

---

# Damage Language

Damage is believable.

Examples

Broken stone.

Split beams.

Scorched walls.

Arrow impacts.

Collapsed scaffolding.

Emergency repairs.

Never random destruction.

---

# Color Language

Warm colors belong to civilization.

Cool colors belong to nature.

Saturated colors are rare.

The player's eye should naturally move toward warm areas.

---

# Camera Language

The camera respects architecture.

Never clip important structures.

Never distort proportions.

Always celebrate scale.

Slow movement.

Purposeful framing.

Cinematic pacing.

---

# Gameplay Language

Gameplay should inherit the world's visual rules.

Enemy paths remain readable.

Tower ranges remain readable.

Projectiles remain readable.

Effects never overpower the environment.

Gameplay clarity is always the highest priority.

---

# AI Rules

Every generated asset must answer:

Does this belong in the Bastion?

Would removing this asset weaken the world's identity?

Does it communicate craftsmanship?

Does it communicate history?

Could this exist in a believable medieval world?

If any answer is "No", redesign the asset.
