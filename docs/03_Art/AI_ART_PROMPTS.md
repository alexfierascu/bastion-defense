# AI Art Prompts

Status: Approved

Version: 1.0

Owner: Art Direction

---

# Purpose

This document standardizes every AI image generation prompt used throughout Bastion Defense.

Every concept image, loading screen, key art, splash screen and environment mockup should originate from these rules.

The objective is consistency.

Not randomness.

---

# Core Prompt Formula

Every prompt should follow this order.

```
Subject

Environment

Architecture

Materials

Lighting

Weather

Season

Composition

Camera

Mood

Rendering Quality

Negative Prompt
```

---

# Identity Sentence

Every prompt should reinforce the following sentence.

> Humanity survives because it learned to build with nature instead of conquering it.

If the image does not communicate this, regenerate it.

---

# Art Style

Use descriptions such as:

Grounded medieval fantasy

Purpose-built fortress

Natural engineering

Weathered stone

Ancient oak

Practical military architecture

Handcrafted materials

Realistic proportions

Subtle atmospheric perspective

Painterly realism

Cinematic composition

Soft volumetric lighting

Never reference copyrighted IPs.

Never ask the model to imitate another artist.

---

# Material Keywords

Always include material descriptions.

Granite walls

Weathered limestone

Aged oak beams

Forged iron

Canvas banners

Leather equipment

Stone foundations

Visible repairs

Ancient roots

# Lighting Keywords

Moonlight

Warm torchlight

Soft ambient light

Golden sunrise

Overcast afternoon

Cold winter light

Rain reflections

Volumetric fog

Soft shadows

Natural bounce lighting

Avoid:

Neon

Bloom overload

Lens flare

God rays everywhere

Extreme HDR

---

# Composition Keywords

Rule of thirds

Strong foreground

Readable silhouette

Single focal point

Natural leading lines

Layered depth

Atmospheric perspective

Framed composition

Clean visual hierarchy

---

# Camera Keywords

35mm lens

50mm lens

Eye-level camera

Slight upward perspective

Natural perspective

Cinematic framing

Avoid fisheye.

Avoid exaggerated wide-angle.

# AI Checklist

Before approving an image ask:

Does it belong to Bastion Defense?

Does it respect the Art Bible?

Would this image still work without fantasy clichés?

Does it communicate craftsmanship?

Is architecture believable?

Is lighting grounded?

Would this image still look good in five years?

If any answer is "No", regenerate.
