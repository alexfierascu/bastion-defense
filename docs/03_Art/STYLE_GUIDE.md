# Style Guide

Status: Approved

Version: 1.0

Owner: Creative Direction

---

# Purpose

This document defines the visual style that every discipline must follow.

It is the bridge between:

- Art
- UI
- Gameplay
- Audio
- Animation
- Rendering

The objective is consistency.

A player should never feel like different teams built different parts of the game.

---

# Identity

Bastion Defense is not about war.

It is about protecting something worth saving.

Everything should reinforce this feeling.

---

# Visual Rules

Everything has a purpose.

Everything has weight.

Everything has history.

Everything has maintenance.

Everything has a believable owner.

---

# Geometry

Large readable shapes.

Simple silhouettes.

Strong proportions.

Minimal unnecessary detail.

Geometry should explain function.

---

# Scale

Players

Small.

Buildings

Large.

Walls

Massive.

Nature

Older than civilization.

The player should always feel protected by the Bastion.

---

# Shape Language

Civilized

Squares.

Straight lines.

Verticals.

Stable geometry.

Nature

Organic.

Curved.

Flowing.

Growing.

Enemies

Broken.

Jagged.

Aggressive.

Irregular.

---

# Materials

Only approved materials.

Granite.

Limestone.

Oak.

Iron.

Bronze.

Leather.

Canvas.

Rope.

Clay.

Slate.

No plastic.

No polished chrome.

No futuristic alloys.

---

# Color

Warm colors belong to civilization.

Cool colors belong to nature.

Red is reserved for danger.

Gold is reserved for importance.

Color should guide attention.

Not create attention.

---

# Lighting

Moonlight

Structure.

Torchlight

Safety.

Sunlight

Life.

Fog

Depth.

Fire

Emotion.

Lighting should support composition.

---

# Motion

Everything moves.

Nothing performs.

Animations should feel observed.

Not designed.

---

# Weather

Weather changes atmosphere.

Never identity.

The Bastion should remain recognizable in:

Rain.

Snow.

Fog.

Storm.

Night.

Morning.

---

# Sound

Wood.

Stone.

Iron.

Leather.

Wind.

Water.

Fire.

Nature.

Avoid synthetic sounds.

Avoid exaggerated fantasy sounds.

---

# UI

The UI belongs to the world.

Never imitate modern dashboards.

Never imitate mobile games.

Every interface should feel handcrafted.

---

# Readability

The player should identify:

Enemies.

Towers.

Objectives.

Resources.

Within one second.

Visual beauty must never reduce clarity.

---

# Production Rules

Before approving any asset ask:

Does it belong?

Does it have purpose?

Does it support gameplay?

Does it reinforce the world's identity?

Would removing it improve the scene?

If yes,

remove it.

---

# AI Rules

Every AI-generated asset must match:

Art Bible.

Materials.

Lighting.

Composition.

Color System.

Visual Language.

If it conflicts with any of them,

reject it.

Every screenshot should immediately communicate one sentence:

"A living fortress built by people who learned to survive alongside nature."

If a screenshot could belong to another fantasy game,

the style guide has failed.
