# Progression Philosophy

Status: Approved

Version: 1.0

Owner: Game Design

---

# Purpose

This document defines how players progress through Bastion Defense.

Progression should reward learning.

Not grinding.

Not repetitive play.

Players should become more knowledgeable before they become more powerful.

---

# Philosophy

Progression is about unlocking possibilities.

Not increasing numbers.

Every unlock should create new decisions.

Never invalidate previous content.

---

# Design Goals

Progression should:

Reward experimentation.

Encourage mastery.

Respect the player's time.

Create meaningful choices.

Support multiple playstyles.

Remain understandable.

---

# Three Types of Progression

## Player Progression

The player's understanding improves.

Examples

Better positioning.

Better timing.

Better economy.

Better tower combinations.

This is the most important progression system.

---

## Account Progression

Permanent unlocks.

Examples

New towers.

Heroes.

Maps.

Game modes.

Lore entries.

Cosmetics.

Account progression expands possibilities.

It should never become mandatory power.

---

## Session Progression

Everything earned during a match.

Examples

Gold.

Tower upgrades.

Temporary buffs.

Repairs.

Technology research.

Session progression resets after the match.

---

# Unlock Philosophy

Unlocks should provide:

New mechanics.

New strategies.

New combinations.

New decisions.

Never:

+20% Damage

+50 Health

+5% Critical Chance

Those belong inside individual matches.

---

# Tower Unlocks

Every new tower introduces:

A new role.

A new strategy.

A new weakness.

A new synergy.

No tower replaces another.

---

# Hero Progression

Heroes unlock:

New abilities.

New tactical options.

New positioning choices.

Never direct statistical superiority.

---

# Campaign Progression

Each mission teaches something.

Examples

New enemy.

New terrain.

New weather.

New mechanic.

New objective.

Campaigns should educate before they challenge.

---

# Economy Progression

Resources become more valuable.

Not more abundant.

Late-game decisions should become harder.

Not easier.

---

# Mastery

Mastery is demonstrated by:

Efficiency.

Consistency.

Adaptation.

Knowledge.

Planning.

Not hours played.

---

# Replayability

Players should replay because they want to try:

Different towers.

Different heroes.

Different strategies.

Different map routes.

Different challenge modifiers.

Never because progression demands repetitive grinding.

---

# Cosmetics

Cosmetics are encouraged.

Examples

Banners.

Gate decorations.

Tower skins.

Hero appearances.

Profile customization.

Cosmetics never affect gameplay.

---

# Completion

A fully progressed player should have:

More options.

Not guaranteed victories.

Skill remains the deciding factor.

---

# AI Rules

When designing progression ask:

Does this unlock new gameplay?

Does it create interesting choices?

Would players be excited to experiment?

Does it avoid power creep?

If any answer is "No", redesign it.
