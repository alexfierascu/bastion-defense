# Purpose

This document defines the emotional journey every player should experience while playing Bastion Defense.

Game mechanics exist to create emotions.

Features exist to reinforce those emotions.

---

# The Emotional Journey

A complete game session should naturally progress through these stages.

```
Curiosity

↓

Planning

↓

Confidence

↓

Pressure

↓

Chaos

↓

Recovery

↓

Achievement

↓

Reflection

↓

"I want one more run."
```

---

# First Impression

The first minute should communicate:

"I understand what I'm protecting."

The player should immediately notice:

- The Bastion
- The Great Tree
- The Bridge
- The Main Gate

Before the first enemy appears, the player should already care about the place.

---

# The First Wave

The first wave teaches.

It does not test.

The player should naturally learn:

- Tower placement
- Enemy movement
- Resource collection
- Wave progression

No tutorial popups unless absolutely necessary.

---

# Building Phase

This phase should feel calm.

The player should feel like an engineer.

Not a frantic clicker.

Music is calm.

Animations are subtle.

UI remains quiet.

---

# Combat Phase

Combat creates controlled pressure.

The player constantly evaluates:

- Weak points
- Tower efficiency
- Enemy priorities
- Resource availability

The battlefield should never become visually overwhelming.

---

# Losing

Losing should feel fair.

The player should immediately know:

Why they lost.

What they could improve.

What strategy they want to try next.

Never create frustration through hidden mechanics.

---

# Winning

Winning should feel earned.

The Bastion survives.

The battlefield shows visible damage.

The player sees the result of their decisions.

Victory should create relief.

Not domination.

---

# Progression

Every session should teach something.

New towers.

New enemy combinations.

New strategies.

New discoveries.

Knowledge is progression.

---

# Replayability

Every new game should encourage experimentation.

Different maps.

Different weather.

Different enemy compositions.

Different tower combinations.

Players should never feel they have solved the game permanently.

---

# Difficulty Curve

Early Game

Learning.

Mid Game

Optimization.

Late Game

Adaptation.

End Game

Mastery.

Difficulty should increase because of decision complexity.

Not because of inflated statistics.

---

# Flow State

The player should spend most of the game inside Flow.

Not bored.

Not overwhelmed.

Challenge should closely match player skill.

---

# Moments of Calm

Every intense combat sequence should be followed by recovery.

Repair.

Upgrade.

Observe.

Plan.

These quiet moments are essential.

---

# Memorable Moments

The game should naturally create stories.

Examples:

The last surviving tower.

A desperate repair.

A perfectly timed ability.

An unexpected comeback.

A flawless defense.

Players should want to share these moments.

---

# Emotional Keywords

Hope.

Responsibility.

Relief.

Determination.

Satisfaction.

Mastery.

Never:

Power fantasy.

Cruelty.

Chaos for its own sake.

"I protected something worth saving.

Next time I'll do even better."
