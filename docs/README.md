# Bastion Defense Documentation

Every implementation decision must originate from these documents.

Documentation has higher priority than assumptions.

# AI Workflow

Every AI agent working on this repository MUST:

1. Read the relevant documentation before changing code.

2. Never invent features.

3. Never contradict documentation.

4. Never introduce new visual styles.

5. Never duplicate systems.

6. Ask for documentation when missing.
