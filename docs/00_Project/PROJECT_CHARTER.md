# Project Charter

Status: Approved

---

# Project

Bastion Defense

Genre

Tower Defense

Platform

Web

Technology

TypeScript

HTML

CSS

Canvas/WebGL where appropriate

---

# Mission

Build the highest quality browser-based Tower Defense game possible.

The game should feel like a premium indie strategy title rather than a browser game.

---

# Vision

The player defends the final living fortress.

Nature and architecture have merged into one organism.

The world feels alive before the first wave begins.

---

# Design Goal

When someone sees a screenshot, they should immediately recognize Bastion Defense.

The game must have a memorable identity.

Never generic fantasy.

Never mobile game aesthetics.

---

# Core Experience

Atmosphere

Meaningful choices

Strategic gameplay

Beautiful presentation

Strong audio

Excellent performance

---

# Non Goals

Pay to win

Mobile style UI

Excessive particle spam

Flashy effects without gameplay value

Random mechanics

Feature creep

---

# Success Criteria

Players immediately understand:

"I am defending the last living fortress."

without reading any text.
