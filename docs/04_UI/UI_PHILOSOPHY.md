# UI Philosophy

Status: Approved

Version: 1.0

Owner: Creative Direction

---

# Purpose

This document defines the User Interface philosophy of Bastion Defense.

The UI must never feel like a website.

The UI must never feel like a mobile game.

The UI exists as part of the world.

Players should feel like they are interacting with the Bastion itself.

---

# Core Philosophy

The UI should disappear.

Players should remember the world.

Not the interface.

The interface supports the experience.

It never becomes the experience.

---

# Design Pillars

## World First

Every menu belongs somewhere.

Every panel has a physical inspiration.

Every interaction should reinforce immersion.

---

## Clarity Above Decoration

The UI should be readable in less than one second.

Information hierarchy is more important than visual effects.

---

## Motion Has Meaning

Animations communicate.

They never exist only to impress.

Movement should reinforce attention.

---

## Quiet Interface

The UI should never compete with gameplay.

No flashing.

No bouncing.

No unnecessary glow.

No excessive particles.

---

# UI Identity

The interface is built from:

Stone

Wood

Iron

Bronze

Canvas

Leather

Parchment

Glass is rarely used.

Plastic never exists.

---

# Visual Language

The interface should feel handcrafted.

Buttons resemble carved wooden plaques.

Panels resemble reinforced notice boards.

Dialogs resemble military reports.

Windows resemble documents placed on a command table.

---

# Color Philosophy

The UI inherits colors from the world.

Primary colors

Stone Grey

Oak Brown

Bronze

Moss Green

Torch Amber

Moon Blue

Accent colors

Deep Red

Soft Gold

Never introduce colors not present in the environment.

---

# Typography

Typography should feel timeless.

Readable.

Confident.

Professional.

Avoid decorative fantasy fonts.

Never use comic or handwritten fonts.

Text hierarchy should remain consistent across every screen.

---

# Icons

Icons should be simple.

Single color.

Easy to recognize.

Consistent stroke width.

Avoid excessive detail.

Silhouette is more important than decoration.

---

# Panels

Panels should feel constructed.

Visible frame.

Subtle texture.

Small imperfections.

Nothing perfectly clean.

No floating transparent cards.

---

# Buttons

Buttons communicate confidence.

States

Idle

Hover

Pressed

Disabled

Every state must be visually distinct.

Hover should be subtle.

Pressed should feel physical.

---

# Cursor

The cursor should support precision.

No oversized fantasy cursor.

No glowing trails.

Hover states should communicate interaction.

---

# Transitions

Transitions should feel cinematic.

Fade.

Slide.

Scale.

Camera movement.

Never use:

Bounce.

Elastic.

Rubber band.

Overly playful easing.

---

# Feedback

Every interaction should provide feedback.

Hover

Visual only.

Click

Visual + Audio.

Errors

Clear explanation.

Success

Subtle confirmation.

Never rely on color alone.

---

# Layout

Whitespace is valuable.

Group related controls.

Avoid clutter.

Players should immediately understand where to look.

---

# HUD Philosophy

The HUD is minimal.

Only critical information remains visible during gameplay.

Everything else is accessible when needed.

The player should spend time looking at the battlefield.

Not the interface.

---

# Accessibility

High contrast mode.

Scalable UI.

Keyboard navigation.

Color-blind friendly indicators.

Reduced motion support.

Readable font sizes.

Accessibility is mandatory.

---

# Audio

UI sounds are made from:

Wood.

Leather.

Paper.

Metal.

Stone.

Avoid electronic sounds.

Avoid exaggerated fantasy chimes.

---

# Performance

UI animations must remain smooth.

Target:

60 FPS minimum.

Avoid layout recalculations.

Prefer GPU accelerated transforms.

Lazy-load heavy menus.

---

# AI Rules

When creating new UI components:

Ask:

Does this feel handcrafted?

Could this exist inside the Bastion?

Does it improve readability?

Does it reduce cognitive load?

Does it match the Art Bible?

If any answer is "No", redesign it.

Elegant.

Natural.

Professional.

Invisible.
